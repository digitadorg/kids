# Titi

Site (landing page) de atividades educativas para crianças.

Feito com React, TypeScript, Vite e Tailwind CSS.

## Como rodar

```bash
npm install
npm run dev      # abre o site em modo de desenvolvimento
npm run build    # gera a versão final na pasta dist/
```

## Estrutura

- `index.html`: título e descrição do site
- `src/App.tsx`: monta a página juntando as seções
- `src/components/`: cada seção da página (Navbar, Hero, Atividades, Benefícios, Depoimentos, Preços, FAQ, Contato, Rodapé)
- `public/`: ícone do site
